# Prompt para kadesh-pet-mobile: botón «Cartel» (cartel con QR e imagen para historias)

## Contexto
La web genera ahora un cartel para imprimir y una imagen para historias de cada caso abierto. Llevan un QR, un enlace corto y un folio (`KP-01234`). El cartel y la imagen viven en la web. La app no los dibuja: solo los abre o los comparte.

## Qué implementar en la app
1. **Botón «Cartel»** en la ficha del animal, para cualquier persona, cuando el último estatus es `lost`, `found`, `rescued`, `abandoned` o `in_adoption`.
   - Abre una hoja con dos acciones:
     - **«Imprimir cartel»**: abre `https://pet.kadesh.com.mx/cartel/{slug}` en el navegador (`Linking.openURL` o el navegador dentro de la app). Desde ahí la persona imprime o guarda como PDF, elige vertical u horizontal y puede quitar el teléfono (sale por defecto).
     - **«Compartir en historias»**: descarga `https://pet.kadesh.com.mx/cartel/{slug}/historia` (PNG de 1080×1920) y abre la hoja nativa de compartir con la imagen (`expo-file-system` + `expo-sharing`), para subirla a Instagram, Facebook o estados de WhatsApp.
   - Ícono: impresora (`PrinterIcon` de hugeicons).
2. **Folio en la ficha (opcional, recomendado).** Muestra «Folio KP-01234» en los datos del reporte, con el número rellenado con ceros a 5 dígitos. Si `folio` viene vacío, no lo muestres.
3. **Enlace corto.** `https://pet.kadesh.com.mx/f/{folio}` redirige a `/animales/{slug}?src=cartel`. Si la app maneja universal links de `/animales/{slug}`, la redirección ya cae ahí. No hace falta manejar `/f/` en la app.

## GraphQL
Para mostrar el folio, pide el campo nuevo en la consulta de la ficha:

```graphql
query GetAnimal($where: AnimalWhereUniqueInput!) {
  animal(where: $where) {
    id
    slug
    folio
    # …los campos que ya pide la app
  }
}
```

```ts
// En el tipo de la ficha:
folio?: number | null;

export function formatFolio(folio?: number | null): string | null {
  if (!folio || !Number.isInteger(folio) || folio < 1) return null;
  return `KP-${String(folio).padStart(5, '0')}`;
}
```

## Reglas y constantes
- Estatus con cartel: `['lost', 'found', 'rescued', 'abandoned', 'in_adoption']`.
- La imagen para historias nunca lleva teléfono. El cartel impreso lo lleva por defecto (`?telefono=0` lo quita) y puede ser horizontal (`?formato=horizontal`); eso se elige en la web.
- URLs: `/cartel/{slug}`, `/cartel/{slug}/historia` y `/f/{folio}` sobre `https://pet.kadesh.com.mx`. Usa el `slug`; si no hay, el `id`.
